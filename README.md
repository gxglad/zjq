# 至冬 · 永冬之国

提瓦特大陆北境 —— 至冬国的互动地图档案站。纯静态，原生 HTML / CSS / JS，无框架、无外部依赖。

**在线访问**：https://gxglad.github.io/zjq/

---

## 它是什么

一张可拖拽缩放的总览图，图上 9 个光点对应至冬的 9 个地区。点击任意光点，
镜头会飞过去并对焦该地区，同时在光点旁边浮出一张档案卡（带引线指向该点），
卡片随地图一起移动，并自动避让屏幕边缘。

顶部依次是：总览 / 序章 / 全屏；底部是横向滚动的地区索引条与坐标、缩放控件。

---

## 入场动画

极简路线：深空中一片留白，细线从中心「生长」出六重对称的雪花纹路
（主脉 → 侧枝 → 末梢分叉，固定 3 秒时间轴，与加载进度解耦）。
加载完成后再等纹路长满，随即碎裂成雪屑、闪一道白光，交棒给地图。

可点右下角「跳过」或按 `Esc` 立即跳过；系统开启「减少动态效果」时自动跳过。

## 目录结构

```
index.html                 页面结构
styles.css                 样式
app.js                     全部交互逻辑（三个模块）
favicon.svg                站标
assets/
  map/overview.webp        总览图（地图底图）
  map/overview.png         总览图 PNG 备用
  region/<id>.webp         9 张地区图（长边 1920）
  region/<id>-sm.webp      9 张缩略图（560px）
```

`app.js` 内部三个模块：

| 模块 | 职责 |
|---|---|
| `Intro` | Canvas 雪花生长 / 碎裂入场 |
| `MapEngine` | 坐标换算、拖拽、滚轮与双指缩放、惯性、镜头飞行 |
| `Card` | 档案卡内容填充、贴点定位、侧向避让、引线绘制 |
| `Ambience` / `Cursor` / `Rail` / `Prologue` | 飘雪、十字光标、底部索引、序章弹层 |

## 交互一览

| 操作 | 效果 |
|---|---|
| 点击地图光点 | 镜头飞至该地区，弹出档案卡并在点旁展开 |
| 拖拽 / 滚轮 / 双击 | 平移 / 缩放 / 放大一级 |
| 点击地图空白处 | 返回全景（收起卡片） |
| 底部地区带 | 横向滚动，点击直达 |
| 卡片「上一处 / 下一处」 | 按编号顺序切换 |
| `←` `→` | 切换地区 |
| `Esc` | 关闭卡片或跳过入场 |
| `R` | 返回全景 |
| 右上「序章」 | 至冬总述（取自 `至冬.docx`） |
